# Что вставить в промпт автоматизации

Один кабинет = одна автоматизация. Общая логика в `bider/SKILL.md`. В промпт вставляется только блок ниже: цифры, которые у ниш разные.

Секреты `AVITO_CLIENT_ID` и `AVITO_CLIENT_SECRET` в текст не писать. Их кладут в секреты этой автоматизации. У каждого кабинета свои ключи.

Скопируйте блок, замените значения и вставьте в Agent Instructions. Рядом положите файл `bider/cabinets/<id>.json` с теми же цифрами. Запуск тогда одной строкой: `python3 avito_autobidder.py --cabinet <id>`.

## Блок для промпта

```text
Следуй bider/SKILL.md. Секрет и токен не печатать и не коммитить.
Ключи только из секретов этой автоматизации: AVITO_CLIENT_ID и AVITO_CLIENT_SECRET.

КАБИНЕТ
- id файла: fabrika-mebeli
- Название: Фабрика Мебели
- Ниша: мебель на заказ
- Лид: чат + телефон (поле contacts, не только звонок)
- Тип оплаты action_type: 5
  5 = пакет кликов, 1 = звонок, 7 = передача контакта в чате

ЦЕНА ЛИДА, ₽
- target_cpl: 1000
- soft_cpl: 1200
- brake_cpl: 1300
- hard_cpl: 1500

ОБЪЁМ
- days: 60
- top_n: 50
- apply_top: 30
- write_bids: нет

ОФОРМЛЕНИЕ КАРТОЧКИ
- vas_max: 1
- buy_vas: нет

ЗАПУСК
cd bider && python3 avito_autobidder.py --cabinet fabrika-mebeli

Если write_bids = да, добавь --apply.
Если buy_vas = да, добавь --apply-vas.
После прогона залогируй в bider/logs/ и запушь ветку xz, как написано в SKILL.md.
Если купил VAS — закоммить bider/state/vas_ledger.json.
```

## Что менять от кабинета к кабинету

| Поле | Зачем |
|------|--------|
| id файла | имя `bider/cabinets/<id>.json` |
| Название | как писать в логе |
| Ниша | чтобы не перепутать автоматизации |
| Лид | чат+телефон, только звонок или только чат — как считаете деньги |
| action_type | за что реально платит этот тариф: клик, звонок или контакт в чате |
| target_cpl | адекватная цена лида |
| soft_cpl | ещё нормально, выше уже мягко режем |
| brake_cpl | отсюда ставки режутся сильнее |
| hard_cpl | край, выше которого режем жёстко |
| days | за сколько дней смотреть чаты и статистику |
| top_n | сколько живых объявлений считать за проход |
| apply_top | скольким писать ставку, когда запись включена |
| write_bids | да = менять ставки в кабинете, нет = только расчёт |
| vas_max | сколько новых цвета/XL/плашек в сутки: 0, 1 или 2 |
| buy_vas | да = покупать эти услуги, нет = только план |

Часы спроса, формула ставки, шаг ±30%, «не трогать мёртвые объявления» и недельный запрет повторной покупки VAS одинаковые для всех ниш. Их в промпт заново не пишите.
