# Этап 7: Экспорт CSV для Авито

## Формат файла

Эталон: `templates/csv-header.csv` и `templates/avito-bulk-upload-example.csv`

### Структура (первые 4 строки — фиксированные)

```csv
,,
Title,Description,Address
Обязательный,Обязательный,Обязательный
Подробнее о параметре,Подробнее о параметре,Подробнее о параметре
```

Строка 5+ — данные объявлений.

### Колонки

| Колонка | Содержимое | Пример |
|---------|------------|--------|
| Title | Заголовок объявления | `Бухгалтер для ИП и ООО — отчёты без штрафов` |
| Description | HTML-текст объявления | `<p>Текст...</p>` |
| Address | Геолокация | `Республика Татарстан (Татарстан), Казань` |

## Правила Description

- HTML валидный для Авито: `<br>`, `<p>`, `<strong>`, `<ul><li>`
- Факты из брифа **не менять** при вариациях
- Опционально в конце: `Исполнитель: Имя`
- Поля с запятыми и кавычками — в двойных кавычках, внутренние `"` → `""`

## Правила Title

- Ключевой запрос + выгода
- Вариации: синонимы, разные углы, гео-модификаторы
- Без кликбейта, не соответствующего тексту

## Правила Address

- Формат: `Регион, Город` или `обл., Город`
- Один город на строку
- Список городов — из брифа (этап 0)

## Масштабирование до N строк

Формула покрытия:

```
строк ≈ базы × варианты_заголовков × варианты_текста × города
```

Пример: 4 базы × 5 заголовков × 10 городов = 200 строк.

### Источники вариативности

1. **Заголовок** — спинтекст или синонимы из этапа 2
2. **Description** — раскрутка спинтекст-шаблона (этап 5)
3. **Address** — перебор городов из брифа

## Именование файла

`output/avito-ads-{slug}-{YYYY-MM-DD}.csv`

## Для 50+ строк

Используй `scripts/expand_to_csv.py` — не генерируй все строки в чате.

```bash
python scripts/expand_to_csv.py \
  --session output/session-{slug}.md \
  --cities "Казань,Санкт-Петербург,Москва" \
  --count 200 \
  --output output/avito-ads-{slug}.csv
```

Если скрипт недоступен — генерируй батчами по 20–30 строк и дописывай в файл.

## Проверка перед выдачей

- [ ] Первые 4 строки совпадают с шаблоном
- [ ] UTF-8 encoding
- [ ] Количество строк = запрошенному (± допустимо при неполном покрытии городов)
- [ ] Нет пустых Title/Description/Address
- [ ] HTML не сломан (закрытые теги)
- [ ] Факты едины во всех вариантах
